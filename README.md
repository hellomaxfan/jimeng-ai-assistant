# 即梦 AI 无水印原图与智能裁剪助手

一个用于 **即梦 AI** (jimeng.jianying.com) 的 Tampermonkey 脚本，提供右键快速保存原图、等比微裁去水印，以及在线交互式裁剪微调功能。

> ⚠️ **免责声明**：本脚本仅供个人学习与技术研究使用。去除水印可能违反即梦 AI 的用户协议，请在使用前知悉并自行承担相关风险。请尊重内容创作者的版权。

## ✨ 功能

- **右键提取原图**：自动剥离 `~tplv-` 图片处理参数，获取最高清原始图片直链。
- **一键快速裁剪**：右键菜单“等比裁掉右上角并保存”，默认向中心收缩 5%，快速去除右上角水印标识。
- **在线裁剪微调**：打开裁剪弹窗，通过滑块实时调整裁剪比例（0%–15%），预览效果后再保存或复制。
- **复制到剪贴板**：支持将原图或裁剪后的图片直接复制到剪贴板（PNG 格式）。
- **Shift + 右键**：临时禁用脚本菜单，恢复浏览器原生右键菜单。

## 📦 安装

1. 确保浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. [点击这里安装脚本](https://raw.githubusercontent.com/hellomaxfan/jimeng-ai-assistant/main/jimeng-ai-assistant.user.js)。
3. 打开 [即梦 AI](https://jimeng.jianying.com/)，在图片上右键即可看到新增菜单项。

## 🔧 使用说明

| 操作 | 说明 |
| :--- | :--- |
| 在图片上 **右键** | 弹出脚本菜单 |
| **Shift + 右键** | 恢复浏览器原生右键菜单 |
| “✂️ 等比裁掉右上角并保存” | 按 5% 比例向中心收缩裁切，一键保存 |
| “🎨 打开在线裁剪微调” | 打开弹窗，滑动调整比例后保存或复制 |
| “💾 保存原始图片” | 保存未经裁切的原始图片 |
| “📋 复制原始图片” | 将原始图片复制到剪贴板（PNG） |

**裁剪比例建议**：通常 **4%–6%** 即可去除右上角「AI生成」标识，且对画面影响最小。默认 5% 是推荐值。

## 🛠️ 技术说明

- 脚本通过正则 `/~tplv-[a-z0-9-]+:[a-z0-9-]+/i` 剥离即梦图片 URL 中的处理参数，还原原始分辨率图片。
- 裁剪采用 Canvas 向中心等比抓取源图区域，并开启高保真重采样（`imageSmoothingQuality = "high"`）。
- 图片下载通过 `GM_xmlhttpRequest` 发起，避免跨域限制。
